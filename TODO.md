## Deferred / divergences from the original spec (decided along the way)

- **Today + Week merged** (your call): no separate Week tab. The dashboard renders any date (`/` = today, `/days/:date`), with a month calendar at `/calendar`. The spec's "Week page" lives in the calendar/day view now.
- **Shopping-list generation** lives on the Food plan (`POST /food/plan/generate_shopping_list`) rather than the spec's `shopping_lists#generate_from_meals` member route.
- **Meal planning actions**: add / remove / edit exist; spec's explicit "replace meal" is just edit for now.
- **Personal records**: only `Exercise#best_set` (heaviest set). No richer PR tracking yet.
- **Reordering** (tasks, list items, template exercises) — spec says "later"; not implemented.
- Nice-to-haves explicitly out of scope until later: streaks, weekly review, bodyweight/photos, pantry, recipe import, barcode, Strava/Garmin/Health, AI suggestions, sharing, export.

## Conventions to keep (so new code matches)

- Scope every query to `Current.user` (e.g. `Current.user.runs.find(...)`), never `Model.find` for user-owned records.
- Money = integer cents (`MoneyHelper#money`); measurements = `decimal`. Forms use a virtual decimal accessor (e.g. `attr_writer :estimated_unit_price`) → convert to cents in the controller.
- Build form objects **unattached** (`Run.new`), never `association.new` for a render — `association.new` injects an unsaved (id: nil) row into the loaded collection and breaks collection renders.
- Turbo Stream pattern: wrap the live region in an `id` and `turbo_stream.replace` it from the controller (see shopping list / workout session bodies).
- Rails 8 enums: options go **outside** the values hash — `enum :x, { a: "a" }, prefix: :x`.
- System tests sign in via the test-only `/test_sign_in/:id` route (avoids auth-form flakiness); the login form itself is covered by controller tests.
- Commits: lowercase title, no "phase" label, basic body, authored Ronan Donnelly, **no** Claude co-author trailer. One commit per phase.
